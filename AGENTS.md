# AGENTS.md: capsule-litellm

Automatic Capsule audit trail for LiteLLM. Every `litellm.completion` or `litellm.acompletion` call produces a sealed, hash-chained Capsule (model identity, SHA3-256 prompt hash, token metrics, latency). Two-line integration, zero app code changes. Apache 2.0.

## Stack

- Python 3.11+, hatchling build.
- Runtime deps: `qp-capsule>=1.0`, `litellm>=1.0`.
- Dev deps: pytest + pytest-asyncio (`asyncio_mode = auto`), ruff (0.15+, rules E/F/W/I/UP/B/SIM, line length 100).
- No mypy config by design (the surface is tiny).

## Commands

```bash
pip install -e ".[dev]"
pytest                 # sync + async callback tests
ruff check .
ruff format .
```

No Makefile. No separate typecheck target.

## Structure

```
src/capsule_litellm/
  __init__.py     public exports (CapsuleLogger)
  callback.py     CapsuleLogger class, LiteLLM callback interface
tests/
  test_callback.py  sync + async integration tests
```

## Style

- **No em dashes** in code, commits, or docs. Use commas, periods, colons, parentheses.
- Type hints on all public functions.
- Keep the callback defensive: `swallow_errors=True` is the default. An audit failure must never break the user's LLM call.
- Hash prompts with SHA3-256 before storing. Never store raw prompt text in the Capsule by default.

Canonical usage:
```python
import litellm
from capsule_litellm import CapsuleLogger

litellm.callbacks = [CapsuleLogger()]
response = litellm.completion(model="gpt-4o", messages=[{"role": "user", "content": "..."}])
```

## Boundaries

**Always:**
- Preserve the two-line integration surface. `litellm.callbacks = [CapsuleLogger()]` is the contract.
- Default to `swallow_errors=True`. Audit failures must never break the user's LLM call.
- Hash prompts. The default Capsule stores the SHA3-256 prompt hash, not the prompt.

**Ask first:**
- Adding a runtime dependency beyond qp-capsule and litellm.
- Breaking LiteLLM version compatibility (test against the oldest declared minimum).
- Changing the default storage backend or requiring configuration beyond the two-line setup.

**Never:**
- Capture raw prompts or completions into the Capsule by default. Opt-in only.
- Introduce deprecated cryptography. Allowlist comes from qp-capsule: SHA3-256, Ed25519, ML-DSA-65.
- Add network calls beyond what LiteLLM itself does.
